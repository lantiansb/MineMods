# 字体

`minemods-pixel.woff`（字体名 MineMods Pixel）是整个界面使用的像素字体，由两套开源像素字体合并而成：

- 方舟像素字体 Ark Pixel Font 12px 比例版（简体中文字形），来自 `TakWolf/ark-pixel-font`，许可证见 `ArkPixel-OFL.txt`。
- 俐方体 11 号 Cubic 11，来自 `ACh-K/Cubic-11`，用于补足方舟像素字体尚未覆盖的字形，许可证见 `Cubic11-OFL.txt`。

两者均按 SIL Open Font License 1.1 使用。合并后的字体改用了自己的名称，没有沿用原字体的保留名称。

字体随应用打包，离线可用；缺少的字形（少量生僻字和符号）会回落到系统字体。
