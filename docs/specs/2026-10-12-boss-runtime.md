# Boss 运行时——第二步

第一步（`2026-10-12-creature-tier.md`）定了档位。这一份写 Boss 档在游戏里多出来的东西。依据是本人 10-12 的要求：Boss 要有玩家视角晃动、地震、方块动画，不同阶段有不同的动画，每个细节都要到位。另一个依据是对热门 Boss 模组常见做法的调研。

原则：
- 全部写成**数据**，由 AI 填参数，Studio 生成 Java。AI 不手写这部分代码，这样每一项都能被结构校验和打包前对账查到。
- 每一项都有上限，不能把服务器卡住。
- 不破坏地形：所有「方块动画」都只是看得见的效果，不改世界里的方块。所以不需要恢复方块，也不受「生物破坏」规则影响。
- 晃屏可以关：玩家设置里的「屏幕效果强度」为 0 时不晃，并且按这个强度缩放。

## 数据：生物 runtime 里的 `boss`

只有敌对（hostile）生物可以写，不写就是 null。

```
boss: null | {
  bar: { color: "pink"|"blue"|"red"|"green"|"yellow"|"purple"|"white", style: "progress"|"notched_6"|"notched_10"|"notched_12"|"notched_20", darken_sky: boolean },
  intro: null | { wake_distance: 4..32, clip: string|null, seconds: 0.5..10, sound: <ABILITY_SOUND_IDS 之一>|null },
  phases: [ { below: 0.05..0.95, clip: string|null, seconds: 0.5..10, bar_color: 同上|null, speed: 1..2, damage: 1..3, abilities: string[] } ]   // 0–3 个，below 从大到小
  death: { seconds: 1..10, xp_bursts: 0..20, explosion: boolean },
  leash: null | { distance: 16..96, reset_seconds: 5..120 }
}
```

### 血条（bar）
- **玩家看到**：Boss 被看见时，屏幕顶上出现它名字的血条，可以有颜色和刻度；`darken_sky` 让天色暗下来。
- **生成**：用原版 `ServerBossBar`。在 `onStartedTrackingBy`/`onStoppedTrackingBy` 里加入、移除玩家，每 tick 更新百分比。有登场时，登场结束才显示血条。
- **限制**：`darken_sky` 只在战斗中打开，Boss 死亡或重置时关掉。

### 登场（intro）
- **玩家看到**：Boss 一开始不动（休眠），玩家走进 `wake_distance` 格才醒。醒来时播 `clip`，吼一声 `sound`。这 `seconds` 秒里它打不动，也不会动。登场结束才开始战斗、出现血条。
- **生成**：用一个同步给客户端的状态（DORMANT、INTRO、FIGHT），写进 NBT。休眠期间不跑 AI 目标，登场期间无敌。clip 用 GeckoLib 的可触发动画。有登场的 Boss 不会自然消失。

### 阶段（phases）
- **玩家看到**：血量掉到 `below`（比如 0.66）时进入下一阶段。
  - 先播变身动作 `clip`，这 `seconds` 秒里打不动、不出招。
  - 然后血条换成 `bar_color`，速度乘 `speed`，伤害乘 `damage`。
  - 只能用这一阶段列出的招式。第一阶段用不在任何阶段里的招式，或者全部招式。
- **一刀打不穿两个阶段**：受伤时如果会跨过下一个阈值，就把血量停在阈值上，触发变身。
- **生成**：阶段号同步给客户端，写进 NBT。招式的出招条件里加上「当前阶段允许」。
- **对账**：变身动作必须在模型里。阶段里写的招式 id 必须存在。

### 死亡（death）
- **玩家看到**：死亡动作播 `seconds` 秒（不是原版的 1 秒）。期间经验分 `xp_bursts` 次喷出；`explosion` 为 true 时，最后有一次只有声光、不破坏方块、不伤人的爆炸效果。
- **生成**：覆盖 `updatePostDeath`，自己计时，到时再移除。战利品照原版掉落表，在死亡开始时掉。

### 离开重置（leash）
- **玩家看到**：Boss 离开出生点超过 `distance` 格、并且 `reset_seconds` 秒内没有玩家在战斗范围里时，它回到出生点，血量回满，阶段回到第一阶段，重新休眠（有登场的话）。
- **生成**：出生点写进 NBT。

## 数据：招式里新增两种事件（events）

所有敌对生物的招式都能用，Boss 档的招式应该用上。

- `{ type: "shake", at, strength: 0.2..3, radius: 4..48, seconds: 0.1..3 }`
  - **玩家看到**：这一刻，半径内的玩家屏幕晃动。离得越远越轻，`seconds` 内逐渐停下。
  - **生成**：服务端给半径内的玩家发一个包（强度、时长、中心点）。客户端用一个 Camera mixin 在 `update` 末尾按随机偏移挪动镜头。强度按距离线性衰减，再乘玩家设置的屏幕效果强度（`distortionEffectScale`），上限 3。
- `{ type: "debris", at, where: "self"|"target"|"hit", hit: number|null, forward, up, left, radius: 1..8, count: 1..24 }`
  - **玩家看到**：这一刻，那个位置的地面裂开冒尘，脚下方块的碎块向上飞起再落下。
  - **生成**：
    - 尘土用 `ServerWorld.spawnParticles` 发 `BlockStateParticleEffect(ParticleTypes.BLOCK, 地面方块)`，按 `radius` 撒成一圈。
    - 碎块用 `BlockDisplayEntity`（显示地面方块，缩小到 0.3–0.5，带向上的初速度和旋转）。服务端每 tick 推它们的位置，8–20 tick 后删掉。
    - 碎块不落地、不放置方块、不掉东西，所以不改世界。
    - 同一时刻全世界存在的碎块最多 64 个，超出的不生成。

## Boss 档的要求（接第一步的档位）

- 档位是 Boss 的生物，蓝图确认后，打包前对账检查：
  - 有没有 `boss`（只要求 schema 里必有的两样：血条和死亡演出），没有就提醒「Boss 档还缺这几项表现：还没有 Boss 设置（血条和死亡演出）」。
  - 阶段（0 到 3 个）、登场、离开重置、巢在 schema 里是可选的，所以不是要求：清单里写成「可有可无」，不写也不算缺（broad21：原先写「至少 1 个阶段」，和 schema 对不上，老手只要两招却被事后提醒缺阶段）。
  - 至少一个招式用了 `shake` 或 `debris`。
  - 死亡动作在模型里。
- 以上是同一份清单（`creature-tier.ts` 的 `tierAsks`，从档位表生成）：蓝图卡片选档位的地方、制作方领任务时的说明、审查员的审查范围、打包前的提醒读的都是它；提醒的语气是「Boss 档还缺这几项表现：……」，不否认已有的血条、招式和能打的战斗。
- 以上都是提醒，不拦打包。
- 制作生物的任务说明里，Boss 档写明上面这些，并说明每一项的取值怎么定：
  - 阶段阈值常用 0.66 和 0.33。
  - 变身 1.5–3 秒。
  - 震屏 strength：落地猛砸 1.5–2.5，吼叫 0.5–1。

## 说明书和测试场

- **说明书**：「怎么玩一遍」里加上 Boss 的测法——走近看它醒来；打到三分之二血，看它变身；被砸的时候屏幕晃不晃；走远看它回去回血。
- **测试场**：有登场的 Boss 在测试场里一开始是休眠的。第一眼要看得到它；测试场不替玩家把它叫醒。

## 不在第二步

- 战斗音乐、Boss 场地和召唤祭坛：第三步。
- 多段碰撞箱、发光层：以后再说。
- 招式的地面预警圈：现有的 effect 事件已经能做。任务说明里要求 Boss 的每个招式在蓝图写好的蓄力里放预警。

## broad6 实机结果与修改（10-12）

- 冰原首领在测试场里实际看到：登场时打不动（300 血不变）、一刀 250 伤害停在阶段线上并换紫色血条、近处晃屏比远处重（相机偏移约 0.088 格对 0.029 格）、碎块约 1 秒落完、地面方块没有变化、经验分 6 次喷出、掉落一片龙鳞、离开 56 格 30 秒后回到出生点回满血并重新睡着。
- 测试场的看不见的围墙挡住了 Boss 的视线（canSee=false），它从不出招；移到空地后才出招。修改：一开始睡着的 Boss 不再围墙（它醒之前不动，醒后离开出生点有 leash 带回）；其他敌对生物仍围墙，说明书写明这圈墙挡住它看你，并给出把它请到面前的指令 `/tp @e[type=…,limit=1] ^ ^ ^6`。
- 说明书里「攻击力是 0」对有招式的生物改成「空手近战是 0，它伤人靠招式」。
- 能力说明里补上「生物不会飞」：原话要飞的，蓝图里把飞单独列成做不了的一点，模型照做翅膀和扑翼动作，生物在地上走。
- broad6 w3：只用 /kill 看死亡，经验一点都不掉（经验只给玩家打死的）。说明书改成给出 `/damage … 1000 minecraft:player_attack by @s`，并说明登场时打不动、有阶段的第一下会停在线上。
