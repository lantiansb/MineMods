# 图上标注与物品持握

## 使用

在模组总览打开模型，转到需要的角度，点击“图上标注修改”。可以圈选、画箭头、添加文字，选中模型部件后新增标注会记录部件名称。填写修改说明后提交。取消会收起并保留当前草稿；撤销、清空和重新截图均可用。工程版本变化时，旧截图仍可查看，需要重新截图才能提交。

MCP 模式将烧录标记后的 PNG 和结构化标注送进同一模型的返工任务。内置 AI 模式也传递真实图片。错误模型、过期版本或损坏图片在创建任务前被拒绝，提交失败保留前端草稿。任务接收成功不代表 AI 已完成修改。

在物品卡片的“物品持握”中选择外观模型，分别调整第一人称和第三人称的左右手位置、旋转、缩放。保存后重开工程仍保留参数，生成的 Minecraft Java 资源包含对应 `display`、立方体几何和实际纹理。左右手参数分别存储，左手镜像只在预览应用一次。

本次物品外观支持无骨骼旋转、动画轨道静止、处于原版模型坐标范围的立方体模型。超出支持范围会明确报错。仅供物品使用的模型按静态物品验收；同时供生物使用的模型仍满足生物验收要求。
