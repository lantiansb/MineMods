# 导入与逆向工作流

此页汇总通用导入、逆向修改、资产重组和验收记录。实现位于 `packages/mod-core` 与 `packages/studio`；真实整合包、反编译产物、运行实例及本机审查包保存在被 Git 忽略的 `.artifacts/` 中。

## 使用入口

1. 在 Studio 首页打开「模组图鉴」，选择本地的模组或整合包。
2. 「背包」按生物、方块、物品、世界等分类一格一格列出内容；内容不超过 8 份的来源自动放入，更大的整合包先选择要看的模组或作者内容。点一格查看卡片和关联内容。
3. 「玩法」在工程没有分析记录时自动开始；连接 API 或外部 MCP 后才会有结果。卡片里的「让 AI 讲讲它」只解释结构化上下文中的已有关系，结果必须通过快照及证据引用校验。
4. 打开右上角「高级」后出现「文件」「改包」「工程信息」：在「文件」中预览模型、缩放或拖动贴图、播放音频、查看与编辑文本，KubeJS、配置等按来源保留为独立资产；需要 Java 候选源码和编译诊断时进入「改包」。静态扫描、反编译、编译和游戏验收分别记录结果。

程序动画入口和独立动画文件是不同内容。没有静态证据支持的模型、贴图、维度或行为保留未知；扫描到类或编译通过也不证明已还原完整游戏行为。

## 工程与导出格式

| 内容           | 本地位置或格式                                                      | 用途                                                                 |
| -------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 原始输入与报告 | `analysis-projects/<id>/source/`、`manifest.json`、`report.json`    | 保存来源归档及扫描范围、哈希和元数据                                 |
| 分析与修改历史 | `runs/`、`working/revisions/`                                       | 保存模型任务、上下文和不可变文本修订                                 |
| 分类资产       | `asset-workspace/files/`、`asset-workspace/manifest.json`           | 按来源提取的文件及其类别和来源记录                                   |
| 资产图与解读   | `asset-workspace/graph.json`、`asset-workspace/graph-analysis.json` | 保存带证据关系及经过校验的解读任务状态                               |
| 逆向工程       | `reverse/`                                                          | 保存模块、候选源码、资源、日志及构建诊断                             |
| 完整修改包     | JAR、ZIP、MRPACK                                                    | 将当前修改覆盖到归档，保留未改内容；外部清单依赖仍需取得             |
| 编辑工程       | `.modwork`                                                          | 分享原始输入、报告和文本修订历史，恢复到新工程 ID                    |
| 逆向工程分享包 | `.modreverse`                                                       | 分享候选源码、资源和构建记录，恢复到新工程 ID                        |
| 分类资产工程   | ZIP                                                                 | 分享分类文件、来源记录、资源图及分析记录；不能直接作为游戏整合包启动 |

路径均相对于分析工程根目录。游戏实例、工具链缓存和分析工程分开管理；构建或临时数据不进入源码提交。分享包含第三方内容的工程时，按导出提示核对授权和许可证。
